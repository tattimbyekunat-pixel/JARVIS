# JARVIS

A beginner-friendly personal AI assistant **web app prototype** built with plain HTML, CSS, and JavaScript. No frameworks, installs, paid services, or build tools are needed to try it.

## Project files

- `index.html` — the page structure and chat interface
- `style.css` — the dark futuristic theme, animated blue core, and mobile layout
- `script.js` — the sample chat behavior

## Try it on an iPhone

1. Open this repository on GitHub and tap `index.html` to view the source.
2. To see the page as a website, use GitHub Pages: open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. Once the deployment finishes, GitHub will show your site link in the Pages section.
3. Make edits in GitHub by opening a file, tapping the pencil icon, editing, then committing your change. Refresh your Pages site after deployment updates.

GitHub Pages is free for public repositories. This project is public, so you can use it without paying for hosting.

## Beginner notes

- The chat currently gives a few sample replies; it is **not connected to a live AI**.
- Your messages stay in the page and are not saved to a server.
- Later, you can learn how to connect an AI API. Never put a private API key directly in browser JavaScript, because visitors can see it.
- Change the color variables near the top of `style.css` to customize the look.

Have fun building JARVIS one small step at a time!
